## スピーカーノート

> 本題の前に、1枚だけ。前回の LT で用意していたのに、話せなかった分です。
> ロボットの学習には GPU が要ります。普段は自宅の GPU 1枚で回していますが、足りなくなったときに AWS で借りられるようにしました。Terraform で EC2 の Spot インスタンスを立てて、学習が終わったら destroy する、使い捨ての構成です。
> Spot はいつ止められてもおかしくないので、10分ごとにチェックポイントを S3 に逃がし、止められたら作り直して、続きから再開します。モデルの置き場所は Hugging Face Hub で、S3 はあくまで再開用の一時領域です。
> 一番気をつけたのは、消してはいけないものを消さないことです。永続データは別の state に分けて prevent_destroy を付け、S3 の削除は、完了マーカーを確認できたときだけにしました。消し忘れて少し残るほうが、ずっとましだからです。
> とはいえ実際には、Spot の容量不足やクォータなど、地雷を10個踏みました。
> 下の帯が全体像です。前回は、フィジカルAIの「学習」をクラウドに出す話。今日は、「判断」をクラウドに置いて、自宅のフィジカルAIを動かす話です。
